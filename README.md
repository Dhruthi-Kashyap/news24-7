# News24-7 - Real-Time News Web Application

News24 is a responsive and dynamic news application built using React.js and Vite that provides real-time news updates using third-party news APIs such as GNews or NewsAPI. The application allows users to explore news across multiple categories including Business, Technology, Sports, Health, Science, and Entertainment.

## Features

* Real-time news fetching using external APIs
* Category-based news filtering
* Infinite scrolling for seamless browsing
* Responsive and modern UI with Bootstrap
* React Router DOM for smooth navigation
* Reusable React components (NewsList, NewsItem, Navbar)
* API key management using environment variables

## Tech Stack

* React.js
* Vite
* Bootstrap
* React Router DOM
* Fetch API
* GNews API / NewsAPI

## Installation

Clone the repository:

```bash
git clone <repo_url>
```

Navigate to the project folder:

```bash
cd news24
```

Install dependencies:

```bash
npm install
```

Create a `.env` file in the root directory and add your API key:

```env
API_KEY=your_api_key_here
```

Start the development server:

```bash
npm run dev
```
